## How to apply a correction

1. Edit the listing in the admin dashboard (make, model, body type, colour, price, VIN,
   mileage, features) and publish.
2. For anything specific to a single video observation, edit `data/vehicle-scan.json`
   and re-run `npm run details` — the website file regenerates from it.
